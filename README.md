## 💻 Run Locally

This repository is a static website. You can preview it locally without
a package installation if no additional build tooling is required.

1.  Clone the repository:

    ``` bash
    git clone https://github.com/Abanoub13-7/ABN_CODE.git
    ```

2.  Open the project folder:

    ``` bash
    cd ABN_CODE
    ```

3.  Open `index.html` in your browser.

For a more reliable local preview, use the Live Server extension in
Visual Studio Code.
